# Contributing to StarBrowser

Bug reports, documentation fixes and focused pull requests are welcome. See the [development guide](docs/DEVELOPMENT.md) for setup and validation.

## Report a bug

Search existing [issues](https://github.com/aafqaq/StarBrowser/issues) first. Include the StarBrowser version, Windows version, steps to reproduce, expected behavior and actual behavior. Use synthetic accounts and data where possible. Remove cookies, login tokens, session archives, private URLs and personal information from logs and screenshots.

Do not post sensitive security details publicly; follow [SECURITY.md](SECURITY.md).

## Propose a change

For a substantial feature, open an issue describing the user problem and proposed behavior. For a small fix, a pull request is enough. Keep unrelated changes separate and explain how you validated the result. Add a regression check when changing session isolation, data migration, plugin permissions or update safety.

Maintain compatibility with existing local data and session archives, or document an explicit migration. Preserve third-party copyright and license notices. Contributions must be code and assets you have the right to submit; contributions are provided under the project's MIT License unless explicitly agreed otherwise.

The project is maintained by [aafqaq](https://github.com/aafqaq). Response times depend on maintainer availability; no support SLA is promised.
